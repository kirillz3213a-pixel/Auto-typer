# AutoTyper (Android, Kotlin)

Автотайпер: вводишь текст в приложении, жмёшь «ГОТОВО», переключаешься в любое другое
приложение, тапаешь по полю ввода — текст печатается сам, символ за символом.
Работает через AccessibilityService (`ACTION_SET_TEXT`), без root.

## Сборка APK

**Вариант A — Android Studio**
1. File → Open → папка `AutoTyper`.
2. Дождись синхронизации Gradle (он сам создаст wrapper).
3. Build → Build APK(s). Файл: `app/build/outputs/apk/debug/app-debug.apk`.

**Вариант B — GitHub (без компьютера с Android Studio)**
1. Залей папку в новый репозиторий на GitHub.
2. Вкладка Actions → Build APK → Run workflow.
3. Скачай `AutoTyper-debug-apk` из Artifacts внутри запуска.

**Вариант C — терминал** (нужны JDK 17, Android SDK и Gradle 8.7):
`gradle assembleDebug`

## Использование

1. Установи APK (разреши установку из неизвестных источников).
2. Открой AutoTyper → «Включить службу» → найди AutoTyper → включи.
   - Android 13+: если переключатель серый — Настройки → Приложения → AutoTyper → ⋮ →
     «Разрешить ограниченные настройки», затем снова включи службу.
3. Введи текст, задай задержку (мс) и символов за шаг → «ГОТОВО».
4. Открой нужное приложение и тапни по полю ввода — начнётся набор.
5. Красная кнопка «СТОП» поверх экрана останавливает ввод в любой момент.

## Настройки скорости
- Задержка 0–5000 мс между шагами (по умолчанию 40).
- Символов за шаг 1–500 (для быстрой вставки больших текстов).
- Случайная вариация скорости — для более «человеческого» набора.

## Структура
- `TyperService.kt` — служба доступности: ждёт тап по полю и печатает.
- `MainActivity.kt` — интерфейс.
- `TyperState.kt` — общие настройки.
- Любой язык/символы/эмодзи поддерживаются — текст ставится напрямую, без клавиатуры.

## Ограничения
- Некоторые поля (пароли, банковские приложения, игры с кастомным вводом) блокируют
  `ACTION_SET_TEXT` — в них набор не сработает.
